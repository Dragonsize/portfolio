// RULES

  • No tools required. The interactive labs (Query Boundaries, Token Validation, Safe Reflection) run in your browser with a built-in request editor.
  • Burp Suite is optional. If you prefer it, proxy the lab and edit requests to that lab's own /api/ endpoint.
  • No scanners. nmap, sqlmap and wpscan find nothing here (the target is a fixed simulation, not a real server) and requests are rate limited. Scanning the hosting platform is not allowed.
  • Stay in scope. Only this lab's endpoints. Nothing here reaches other sites, files or accounts.
  • Progress is local. It lives in this browser only. It is not a score or an identity.
